# Task 1: Data Immersion & Wrangling

### Objective
The objective of this task is to understand, clean, and prepare raw data for analysis by identifying and fixing data quality issues.

---

### Dataset
The project uses a Superstore Sales dataset containing information about:
- Orders
- Customers
- Products
- Sales, Profit, and Quantity

---

### Steps Performed

1. Loaded the dataset and studied its structure.
2. Identified missing values, duplicates, inconsistent formatting, and outliers.
3. Cleaned the data using Python.
4. Standardized text and date formats.
5. Created new features such as age and revenue.
6. Saved the final cleaned dataset for analysis.

---

### Deliverables

- Cleaned Dataset
- Data Profile Report
- Missing Values Report
- Duplicate Records Report
- Outlier Report
- Data Dictionary

---

### Tools Used

- Python
- Pandas
- NumPy

---


### Conclusion

The dataset was successfully cleaned and transformed into a structured format, making it ready for further analysis and visualization in upcoming tasks.
